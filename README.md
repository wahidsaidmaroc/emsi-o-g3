# emsi-o-g3

Nova Chat is a React + Vite frontend for an AI chatbot experience inspired by ChatGPT. The interface focuses on readability, strong contrast, clear hierarchy, and a fast conversation flow.

## Run locally

1. Install dependencies: `npm install`
2. Start the development server: `npm run dev`
3. Build for production: `npm run build`

## Included

- Responsive dark chat layout
- Left sidebar with quick prompts
- Message stream with assistant and user bubbles
- Composer with loading feedback
- Mobile-friendly structure
